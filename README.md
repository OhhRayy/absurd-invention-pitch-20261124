Entry for the [make.fun bounty "One-Sentence Absurd Invention Pitch"](https://make.fun/bounty/u-suroso-69-one-sentence-absurd-invention-pitch-5326c34a).

## What it does

`main.py` writes one sentence to `/output/entry.txt` pitching a ridiculous invention that fixes a tiny everyday annoyance. The program is deterministic (the same bytes on every run), uses no network, and needs no input.

The sentence:

> A toaster that files a formal apology before burning your bread, so at least the betrayal comes with paperwork.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
